# Zimu Card Game

This is the Python engine foundation for the 100-card registry, Zimu deployment, and lane clashes. Rules transcribed from the design notes, including currently unresolved conflicts, are in [RULES.md](RULES.md).

Try the [Card Studio](design/card-studio.html) for a live card-face preview, and see [CARD_DESIGN.md](CARD_DESIGN.md) for the visual and print specifications.

Run the test suite from this directory with:

```sh
python -m unittest -v
```
